# Manuscript reproduction

The complete SGCB 0.5.9 reproduction archive is available from the
[GitHub release](https://github.com/aeqby770/SGCB/releases/tag/v0.5.9).
It includes fixed input matrices, comparator outputs, saved fits and all
reported results. Extract it and start with `REPRODUCE.md`.

The code in this directory mirrors the archive:

- `experiments/`: benchmark evaluation, null controls and biological analyses.
- `visualization/`: figures generated from the saved results.
- `writing/`: manuscript, tables and editable revision-document generation.
- `development/`: package setup and the conditional CV-squared sensitivity.

Install the R package using the repository's main README. Running the
installed example does not require downloading the full reproduction archive.
The original submission and its reproduction files remain at tag `v0.4.1`.
